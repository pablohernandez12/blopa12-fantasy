# BLopa12 Fantasy Intelligence V3 Web

## Abrir sin instalar nada
Puedes abrir `index.html` localmente en tu navegador.

## Publicar gratis en Vercel
1. Crea una cuenta en GitHub.
2. Sube estos archivos a un repositorio.
3. En Vercel: Add New Project → Import Git Repository.
4. Framework: Vite.
5. Deploy.

La web actual es el frontend. Para datos reales automáticos hay que añadir un backend/API autorizado.
